# Task Manager API

CRUD funcional de tareas construido con Node.js y Express. Proyecto practico
de la Tarea 3 (Uso de Git y Git Flow).

## Instalacion
```
npm install
```

## Ejecucion
```
npm start
```
Servidor en http://localhost:3000

## Endpoints
- GET    /api/tasks
- GET    /api/tasks/:id
- POST   /api/tasks
- PUT    /api/tasks/:id
- DELETE /api/tasks/:id

## Flujo de trabajo
Desarrollado con Git Flow: ramas `main`, `dev`, `qa`, y 5 ramas
feature/hotfix integradas mediante Pull Requests.
